# AutoClerk — reading the night audit

AutoClerk's night audit is **several separate PDFs**, one report each.

## Which hotel

The first line is the hotel's **name as set up in AutoClerk**, followed by its
street address and phone number. AutoClerk prints no short hotel code, so the
hotel is recognised by that printed name.

## Which night

The header prints `Date:` with the date written out (for example
`July 08, 2026`) and the time it was run. That is the day the report was
printed, which is usually the morning after the business night it covers.

## Transaction Summary — the money

- One line per transaction code with its description and the amount for the
  night.
- Revenue, taxes and payments are all listed; the description says which.
  Payments are money coming in, not revenue. Taxes are held for the
  government, not revenue.

## Manager's Report — the rooms

- Sections such as **Occupancy** and **Statistics**, each line a label and its
  figures: `Occupied`, `Occupied Percent`, `ADR`, `REVPAR`, `Arrivals`,
  `Departures`, `In-House`, `No Shows`.
- The Manager's Report does not print the size of the hotel; the room count
  comes from what the owner set for the hotel.

## Revenue by Rate Plan — who stayed

Rooms and revenue by rate plan for the night.
